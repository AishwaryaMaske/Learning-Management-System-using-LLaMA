# Learning Management System using LLaMA and SearXNG

## Project Overview
An AI-powered Learning Management System designed to provide intelligent educational search, personalized learning pathways, and interactive learning assistance using LLaMA and SearXNG.

## Technologies Used
- React.js
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- LLaMA 3.2
- SearXNG
- YouTube API

## Key Features
- AI-powered learning assistant
- Intelligent educational search
- YouTube video recommendations
- Personalized learning pathways
- Topic decomposition
- Adaptive user feedback system

## Project Modules
1. Dashboard
2. LLaMA Tutor
3. YouTube AI Search
4. SearXNG Search
5. Learning Pathways
6. Adaptive Feedback
7. Research and Specifications
